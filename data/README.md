# Benchmark strates

The three strates of the universal trunk, with their **embedded, frozen
splits** (R3.1/R3.2) and a signed `manifest.json` per strate (R3.3) — SHA-256
of every instance, per-split counts, provenance, and the manifest's own
content hash. The manifest is the protocol-freeze unit (G2).

| strate | splits | instances | source |
|---|---|---|---|
| `miplib_s` | train (19) / test (8) | 27 | branch-search-trees dataset (Zarpellon et al., AAAI 2021), [osf.io/uvg5f](https://osf.io/uvg5f/) |
| `milp_l` | easy (57) / hard (16) | 73 | MIPLIB 2017 with the Mamba easy/hard split (github.com/doctor-watson626/Mamba-Branching) |
| synthetic Ecole families | — | — | generated by `gyozas.instances` (no on-disk strate needed) |

The instance files are not stored in git (some are very large); the signed
manifests are. Rebuild the instance files with `scripts/build_strate_data.py`,
then check a strate is intact:

```python
from gyozas.strates import Strate

strate = Strate.load("data/miplib_s")
problems = strate.verify()   # [] when every instance matches its hash
```
